¿Cómo maneja Foundation los textos?

Foundation nos permite hacer uso de utilidades tipográficas y configuraciones por defecto que facilitan la lectura:

  • Jerarquía automática: Todos los encabezados (<h1> al <h6>) tienen márgenes y tamaños responsivos ya calculados.
  • Clase .lead: Como vimos en el párrafo superior, usar esta clase aumenta ligeramente el tamaño de la fuente. Ideal para el primer párrafo de un artículo o subtítulos importantes.
  • Alineación: Clases como .text-center, .text-left o .text-right te permiten controlar la justificación sin tocar tu CSS.
  • Pesos visuales: Las clases .stat (para números gigantes en estadísticas) y .subheader (textos ligeramente atenuados y delgados) ayudan a dar variedad visual a la información de forma muy limpia.

Al sobrescribir el font-family en nuestro archivo app.css para el elemento body, Foundation hereda inteligentemente esta nueva fuente en todos sus componentes: botones, tarjetas, etiquetas e inputs de los formularios.

Aprende sobre el Componente Card en Foundation

Las Cards (tarjetas) son un contenedor flexible y extensible en Foundation, diseñado para agrupar contenido relacionado en una caja visualmente definida. Son componentes muy versátiles para mostrar artículos, productos o perfiles.

¿Cómo funciona la estructura?

El componente se construye ensamblando clases específicas como si fueran bloques de construcción:

  • .card: Es el contenedor principal de la tarjeta. Agrega el borde, fondo y controla que los elementos internos respeten los bordes redondeados (border-radius).
  • .card-divider: Se usa como encabezado o pie de tarjeta. Tiene un color de fondo ligeramente distinto para contrastar y separar el contenido.
  • Imágenes: Las etiquetas <img> colocadas directamente en un .card (fuera de una sección) se extienden inteligentemente de borde a borde.
  • .card-section: Es el contenedor para texto, botones y otros elementos. Proporciona el padding (espaciado interior) necesario para que el contenido respire. Puedes tener múltiples .card-section en una sola tarjeta.

Nota responsiva: Aunque en tu ejemplo propusiste usar style="width: 300px;", aquí hemos omitido ese ancho fijo y colocado la tarjeta dentro de una columna del grid (large-4 cell). Esta es la forma recomendada en Foundation, ya que permite que la tarjeta sea responsiva y se adapte a cualquier tamaño de pantalla de forma fluida.

¿Cómo se estructuran los formularios?

Foundation trata de mantener el HTML lo más limpio y semántico posible, evitando sobrecargarte de clases CSS en cada input:

  • Envoltura con <label>: Es la forma más recomendada en Foundation. Envuelves el <input> directamente dentro de la etiqueta <label>. El framework aplica estilos a todos los inputs por defecto y se asegura de que queden bien alineados debajo del texto de su etiqueta.
  • El Grid como aliado: Nota cómo usamos el grid (div class="grid-x" y celdas large-12 cell) dentro del <form>. Así puedes crear formularios de varias columnas muy fácilmente.
  • .help-text: Si necesitas añadir instrucciones debajo de un input (como en la contraseña), agregas un párrafo con esta clase. Lo estiliza sutilmente y reduce sus márgenes.
  • .input-group: Es un contenedor muy útil para adjuntar iconos o texto fijo a un input (como el "https://" de nuestro ejemplo). Consta de un .input-group-label para los anexos fijos y un .input-group-field para el campo editable propiamente tal.
  • Estilo global: Para que nuestro formulario resalte un poco más visualmente, he envuelto el formulario en un contenedor usando la clase .callout.secondary. Esta clase añade un fondo gris claro, un borde sutil y un poco de espaciado interno automático.
